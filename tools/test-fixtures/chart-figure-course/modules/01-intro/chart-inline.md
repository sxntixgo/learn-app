A bar chart with data written directly in the fence — the default form
(design §6.3: "chart data is inline by default").

```chart
kind: bar
caption: Lessons completed per module
data:
  - { label: MCP servers, value: 5 }
  - { label: Agents, value: 6 }
  - { label: Code review, value: 3 }
```
