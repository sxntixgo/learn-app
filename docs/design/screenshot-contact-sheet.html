Known and Accepted Differences (from plan)

These are deliberate design choices, not defects:

  • Catalog filter field: Uses ?tag= (inferred from CourseSummary), not a spec-defined field. Confirmed judgement call.
  • Search wide-tier structure: Single 640px column (matches Course layout), not a grid. Judgement call per artboard brevity.
  • `hasRealProgress` hiding not-started degrees: PL9 explicitly shows "not-started degree and prerequisites"; the implementation hides it because `listDegreeProgress` has no enrolment awareness and cannot distinguish "0% and never touched" from "0% but pursuing it". Ratified by repo owner 2026-09-07.
  • Non-owner profile view cannot match PL9: The public contract (`ProfileBadge` earned-only, `ProfileDegree` omits curriculum) deliberately differs from owner view. Ratified by repo owner 2026-09-07.
  • Routes with no artboard (grading, invitations, admin, etc.): Restyled by repo owner's explicit decision 2026-09-07. Spec says "out of scope, left as they are"; they are sampled below for record-keeping but have no artboard to compare against.
  • `/no-access`: Deliberately left unchanged — already on token layer, already centred.
